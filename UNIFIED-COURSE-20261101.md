# Единый маршрут и диагностика · 01.11.2026

Основной маршрут расширен с 22 до 51 зачётного этапа. Число 51 — не количество новых задач: прежние 22 сохранены; 19 уже существовавших практических блоков/условий включены в маршрут; добавлены 10 новых диагностических условий. Вводные блоки состоят из нескольких действий, но каждый учитывается одним этапом.

## Восемь разделов

1. Знакомство с устройством, безопасностью, инструментом и координатами.
2. Координаты и первый процесс, затем самостоятельный проход.
3. Измерение, допуск, подготовка и полный цикл.
4. Чтение G-кода, программа с наладкой и самостоятельный перенос.
5. Пять токарных операций: торец, повторное торцевание, канавка, конус, две канавки.
6. Четыре изделия по разным чертежам с наладкой, обработкой, измерением и отчётом.
7. Шесть фрезерных условий XYZ: воздух, крепление, материал, послойная глубина, державка, колонна корпуса.
8. Десять диагностических задач ниже.

## Новые задачи

| Условие | Действие учащегося |
|---|---|
| Быстрый ход в материале | Воспроизвести отказ и заменить опасный участок рабочей подачей |
| Неподходящий резец | Сопоставить торцевой ход и установленный инструмент |
| Пластина в канавке | Исправить порядок радиального и осевого отвода |
| Избыточный торцевой съём | Распределить обработку на допустимые проходы |
| Ошибка G54 | Восстановить известную координату торца, не маскируя ошибку кодом |
| Крепление на пути | Построить безопасный перенос с промежуточными точками |
| Свободная фреза, столкновение державки | Учесть всю заданную оболочку сборки |
| Колонна корпуса | Проложить обход неподвижного препятствия |
| Выход за перемещение оси | Исправить координату по заданной конечной точке |
| Врезание без вращения | Проверить состояние шпинделя перед рабочим движением |

Диагностика: проверка исходного варианта на изолированной копии → определение причины → собственное исправление → повторная проверка настоящим движком тренажёра. Проверяются геометрия/наладка либо конечная точка/сетка материала, а не строковое совпадение программы. Допускаются эквивалентные решения; ошибки и открытие разбора сохраняются. Подсказка не подменяет самостоятельный результат, помощь отображается отдельно. Это учебная диагностика подготовленной копии, не подтверждение изготовления и наладки реального станка.

## Прогресс и совместимость

Старые идентификаторы 22 этапов сохранены. Старые зачёты не стираются, новые этапы не выдаются по прежнему флагу завершения. Подтверждение практики извлекается строгим воспроизведением журналов, включая сохранённые истории; дубли не повышают счётчик. Можно просмотреть завершённое условие без замены текущей попытки. Основная кнопка ведёт к первому незавершённому этапу. Журнал наблюдений читает прежние снимки из 22 строк и новые из 51; администратор видит диагностику и актуальный общий маршрут.

Мастерская остаётся свободной песочницей. Новых заявлений о соответствии ГОСТ нет: предметная проверка SAFE-01/CLAUSE-REVIEW остаётся открытой; автоматическое отслеживание изменений стандартов — завершающий этап РФ-7.

## Дальнейшее углубление

Следующие семейства требуют отдельных моделей и приёмки: сверление и растачивание отверстий, резьба, выбор режимов по материалу и инструменту, фрезерные карманы и контуры с контролем, самостоятельные итоговые изделия. Не выдаём перечисленное за реализованные операции. Пилот отложен по приоритету владельца до расширения учебного содержания.
