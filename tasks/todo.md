# Очередь разработки курса

Основание: [подробный план и источники](plan.md), 04.11.2026. Т01–Т03 и Т08 выполнены; остальные пункты ниже — будущая работа. По просьбе пользователя Т02–Т03 и первый пакет углублённых операций объединены в один этап; предметные проверки и оставшиеся учебные блоки сохраняются отдельно. Пути с пометкой «новый» для предстоящих задач предлагаются; окончательное размещение уточнить по текущему коду. S — небольшой пакет, M — несколько связанных изменений; неизвестную геометрию сначала исследовать, а не обещать срок.

Для каждой задачи: указанные критерии, профильная проверка, затем проверки сборки. Перед выпуском связанного пакета — `npm test`, `npm run test:server`, `npm run build:demo`, `node scripts/check-build.cjs`, браузер и сохранение через перезагрузку. После каждых 2–3 задач — контрольная точка; не выдавать только модульный тест за педагогическую приёмку. Ключи, реальные аккаунты и рабочие базы не включать в тестовые фикстуры.

- После Т01–Т04: карта содержания и критерия готовности согласована с реальными возможностями движка; исторические зачёты не сбрасываются.
- После Т08–Т10: первый глубокий токарный блок самодостаточен для авторской проверки.
- После Т12–Т14: базовая фрезерная ветка имеет действие, диагностику, перенос и контроль.
- После Т15 и Т20: до разработки уроков доказана геометрическая выполнимость нового семейства.
- После Т19, Т23 и Т28: браузер, облако, экспорт, версия модели и ресурсный тест соответствуют расширению.
- После Т32–Т33: выводы об эффективности основаны на наблюдении; прямое сравнение с конкурентом допускается только при сопоставимом доступе и протоколе.
- После Т34–Т36: РФ-7 не подменяет предметную экспертизу и не считает недоступность источника отменой ГОСТа.
