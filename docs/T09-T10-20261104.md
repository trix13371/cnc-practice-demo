# Т09–Т10 — диагностика и самостоятельное изделие

Реализовано 04.11.2026 по одобренному объединённому пакету. Спецификация: [SPEC-T09-T10.md](SPEC-T09-T10.md).

## Диагностика

Углублены десять существующих условий. Для X/Z движок графической проверки возвращает первый отвергнутый кадр: строку, текст, рабочие/машинные/фактические координаты до отказа, запрошенное движение, инструмент, G54 и состояние вращения. Движение, получившее отказ, не добавляется к выполненной траектории. Это описание проверяемого кадра, не измеренная точка физического контакта.

Для XYZ сохранены строка маршрута, начало/конец, часть сборки и препятствие. Показаны проекции XY и XZ, включая габариты державки. Подпись поясняет скрытую третью координату и отличие отвергнутого движения от выполненного.

Исходная проверка сохраняется отдельно от последней проверки исправления. Полный проверенный текст доступен с обозначенной строкой отказа. Ученик сначала воспроизводит отказ, затем выбирает причину и изменяет программу/наладку. Прежние проверки причины, конечной геометрии, полного пути и G54 продолжают действовать. Администратор дополнительно видит исходную строку и код отказа. Неизвестный журнал в виджете не заменяется новой работой.

## Самостоятельный проект

Добавлен RF5-SHAFT-05: Ø38, вылет74 и отдельный зажим15; A Ø30 длина22; B Ø33 длина26; C сохраняетсяØ38. Редактор программы пустой. Маршрут ученик составляет из переходов, программу пишет самостоятельно; это не произвольное конструирование геометрии.

Новый припуск требует промежуточного чернового диаметра. Проверены два порядка: общий черновой→общий участок→передняя шейка; предварительная обработка передней шейки→общие переходы. Оба исполняются прежним X/Z-движком. План и графика работают на копии, зачёт требует исполнения на собственной заготовке, шести свежих записей и итогового протокола. Неполный контроль и неверная вычисляемая длина B не принимаются.

Пакет чертежа/наладки/контроля/обязательных критериев строится из канонических task и rows; [project-shaft.json](project-shaft.json) генерируется `npm run build:project-documents`. Доступен экспорт пакета из интерфейса. Режим работы песочницы не менялся.
