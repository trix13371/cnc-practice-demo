# Проверка понятности новых условий — 04.11.2026

Объём: шесть условий пакета metrology, их общая форма, схема, промежуточные состояния и переходы. Изолированная браузерная проверка использовала тестовые журналы вне аккаунтов; синтетические результаты не переносились в основную базу.

| Условие | Проверено и исправлено |
| --- | --- |
| Поверхность, прибор и два сечения | Связь шейки A и базы B с разрезом; выбранные сечения 1/2 теперь обозначены на схеме; измерительные кнопки говорят «Измерить»; виден счётчик записей |
| Разрез и глухое отверстие | Подпись B указывает внутрь светлой полости, с отступом от стенки; подпись снова называется «отверстие»; пояснены полость и материал; на виде сбоку внутренняя подпись скрыта |
| Один замер не подтверждает участок | Счётчик показывает, что требуется два сечения; итоговые решения скрыты до записи всех необходимых замеров и пределов |
| Уточнение пограничного результата | Статус уточняющего контроля показан рядом с условием; предварительные записи помечены; отдельно считаются записи микрометра; вручную выполнены два новых измерения и получен зачёт |
| Повтор после доработки | В начале экрана различаются исходное состояние 1 и состояние 2; старые записи явно устарели; новое решение недоступно без свежих записей |
| Самостоятельная втулка | A и B имеют отдельные счётчики замеров и пределов; при переходе на B скрывается сообщение об успешной записи пределов A; обозначение отверстия проверено и для сквозной геометрии |

Дополнительно устранён общий дефект формы `.start-answer`: у поля был нижний отступ 15 px, который участвовал во flex-выравнивании. Внутри этой формы отступ обнулён в каноническом `styles/layout.css`; генерируемые CSS и demo пересобраны. В браузере нижние края обоих input и кнопки совпали: 1347,0625 CSS px в проверяемом состоянии. На ширине 390 px поля и кнопка переходят в одну колонку, элементы формы не выходят за ширину страницы. Схема на узком экране сохраняет собственную горизонтальную прокрутку для читаемости подписей.

«Убрать контролируемую деталь» переименовано в «Разомкнуть прибор»: действие не удаляет и не заменяет деталь. Сохранённые пределы выводятся рядом с формой, даже когда поля черновика пусты.

Журналы, критерии, размеры, модели приборов и зачёты не изменены. UI показывает готовность на основе проверенных моделью записей текущего состояния. Сервер продолжает самостоятельно выводить результат из журнала; скрытие кнопки не заменяет его проверку.

Проверки: все 52 группы `npm test`; дополнительные проверки UI до/после исправлений; `tests/client-assets.test.cjs`; сборки styles/demo и проверка 75 скриптов. Для промежуточных состояний уточнения, устаревших записей и смены поверхности тесты сначала воспроизвели проблему, затем прошли. Проверка автора в браузере не является исследованием понятности на новичках.
