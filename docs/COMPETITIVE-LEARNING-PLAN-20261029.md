# План развития обучения: «Диполь» и Autodesk

Дата: 29.10.2026. Статус: аналитика и план, новые функции этим документом не реализованы.

## 1. Цель и предел сравнения

Цель продукта: русскоязычный новичок без станочного опыта самостоятельно выполняет и объясняет полный виртуальный цикл простой токарной детали по новому чертежу. Следующий уровень — подготовка к занятиям с преподавателем на оборудовании. Виртуальный зачёт не присваивает квалификацию и не разрешает реальную работу.

Сравниваем определённые продукты: тренажёр «Диполь» «Токарные работы на станке с ЧПУ. Чтение чертежей. Резание. Программирование» и учебную связку Autodesk Learn / Fusion CAM Turning. Курс Haas используется как дополнительный пример перехода к физическому изделию; это фрезерный курс, его операции не приписываются токарному тренажёру.

Изучены открытые программы, конкретные задания, руководства и иллюстрации. У «Диполя» прочитаны руководства эксплуатации, установки и функциональные характеристики; визуально просмотрены страницы 5 и 8 руководства эксплуатации. У Autodesk разобраны условия и рубрика проекта корпуса ручки, тренировочное задание чернового точения, описание сертификации и документация симуляции. Лицензированные приложения не запускались, курсы целиком не пройдены, интервью с их учениками не проведены.

Обозначения: **факт** — прямо подтверждён источником; **риск** — наша педагогическая интерпретация; **не установлено** — недостаточно доступа. Отсутствие функции в открытой документации не доказывает её отсутствие в продукте. Не заявляем превосходство над конкурентами до сопоставимого исследования.

## 2. Оценка «Диполя»

**Факты по [карточке продукта](https://www.tacis-dipol.ru/corp/catalog/kompyuternyj-trenazher-tokarnye-raboty-na-stanke-s-chpu-chtenie-chertezhej-rezanie-programmirovanie/):** три модуля — чертежи, программирование, резание; соответствие чертежа и 3D, технические требования и расчёты; фиксированные и случайно изменяемые параметры; исправление программы, подбор инструмента и обработки. Сильнейшая сторона — широкий набор прикладных задач вокруг профессии. Для нас это базовый конкурентный уровень, а не уникальная будущая функция.

**Факты по [руководству эксплуатации](https://next.tacis-dipol.ru/index.php/s/Q9WgmRpxecGckb5):** условие задания автоматически сворачивается; длительное чтение требует наведения мыши или Alt. Есть осмотр 3D и ввод значений через размер чертежа; отчёт содержит баллы, время и ответы. Риск для новичка — необходимость одновременно помнить условие и осваивать скрытые способы управления. Текущую версию интерфейса в работе не проверяли.

По [руководству установки](https://next.tacis-dipol.ru/index.php/s/KjwB8sNji3wxaWF) описана установка под Windows с административными правами / доступом к реестру. Это подтверждённое ограничение описанной поставки при домашнем старте. Локальная установка одновременно может быть преимуществом для аудитории без интернета.

По [функциональным характеристикам](https://next.tacis-dipol.ru/index.php/s/MXtRTG2TiSWYyNC) преподаватель назначает практику и получает отчёты. Поэтому один кабинет администратора не будет нашим преимуществом.

**Не установлено:** качество объяснения первой ошибки, полнота пути с нулевыми знаниями, адаптация к причинам затруднений, отложенный перенос навыка, точность физической модели, доступность с клавиатуры. Проверять в демо по единому сценарию, не выдавать за недостатки.

## 3. Оценка Autodesk

**Факты:** [Creating Toolpaths for a CNC Lathe](https://www.autodesk.com/learn/ondemand/course/fusion360-creating-toolpaths-for-a-cnc-lathe-associate) связывает подготовку токарной обработки, траектории, проверку и выпуск кода. Это обучение CAM-процессу в Fusion; его нельзя отождествлять с обучением панели оператора физического станка.

В [тренировке чернового профиля](https://www.autodesk.com/learn/ondemand/module/practice-exercise-create-a-turning-profile-roughing-operation) есть исходные данные и видео решения. Сильная сторона — конкретное действие после объяснения. Риск: просмотр решения способен подменить самостоятельный перенос; это проверяется только новой задачей без открытого решения, а не фактом просмотра видео.

В [проекте корпуса ручки](https://files.upskill-dev.autodesk.com/public/curriculum-toolkit/cam-turning-projects/230210_Custom-Pen_Pen-Body.pdf) дан производственный контекст, модель, чертёж, план, наладочные и контрольные материалы. Рубрика проверяет полноту траекторий, удаление материала и критические размеры; эффективность рассматривается дополнительно. Это сильнейший ориентир по целостности проекта. Риск для полного новичка — сразу требуется совокупность уже освоенных навыков; такой проект подходит после вводных занятий. Краткая рубрика требует более подробной диагностики причин ошибок.

Есть подтверждённый редакционный дефект: [страница токарного техплана](https://www.autodesk.com/learn/ondemand/tutorial/challenge-exercise-create-a-lathe-process-plan) содержит описание про листовой металл. Это отдельный пример несогласованности, не доказательство низкого качества всей библиотеки.

[CAM Turning Associate](https://www.autodesk.com/certification/all-certifications/cam-turning-associate) описывает экзамен выбранных ответов без работы в ПО. Это граница проверки данного экзамена; она не отменяет практические проекты Autodesk и не делает наш внутренний зачёт равноценным профессиональному сертификату.

[Документация симуляции](https://help.autodesk.com/view/fusion360/ENU/?contextId=MFG-REF-SIMULATION) различает симуляцию обработки и симуляцию с машиной; последняя описана для фрезерных установок. Нельзя приписывать токарному курсу все возможности машинной симуляции. Наша упрощённая модель пока существенно уже Fusion по операциям и геометрии.

**Не установлено:** качество автоматического индивидуального разбора, удобство всей последовательности для человека с нуля, текущая доступность всех ресурсов конкретному пользователю РФ, сравнительная эффективность обучения.

## 4. Где сейчас отстаём

По исходникам: 24 урока, 22 шага прежнего пути, 35 статей, вводная сессия и измерительное занятие по девять действий, практика программирования, полные циклы и свободная мастерская. Количество разделов не подтверждает качество обучения.

Основные пробелы: разные учебные модели и обозначения; недостаточно цельных изделий; часть заданий слишком близка к разобранным ответам; мало независимых вариантов; только начальные средства преподавателя; нормативная проверка и пилот не завершены. В мастерской нет растачивания, сверления, резьбы, отрезки и дуг; наличие исходной трубы не означает обработку отверстия.

Начальную цель «будем лучше» ограничиваем тремя проверяемыми направлениями: понятность входа с нуля, диагностический разбор действий, самостоятельное решение новой задачи. Не обещаем превосходство по полноте CAM или производственной достоверности.

## 5. Единый стандарт нового урока

Каждый урок имеет паспорт: исходные умения, одно основное наблюдаемое умение, объяснённые термины, сцену, действия, проверочные условия, эталон и нормативные основания, ограничения модели, версии.

Последовательность: короткое объяснение → действие с видимым последствием → прогноз или объяснение причины → новое условие → повтор через 3–7 дней. Помощь доступна в курсе и записывается отдельно. Неверная попытка не стирается после исправления. Вариант проверки отличается геометрией или ситуацией, а не только перестановкой вариантов ответа.

Условие остаётся доступным без таймера, наведения и удержания клавиши. На первом плане: цель, сцена, следующее действие и результат. Детали открываются по запросу. Цвет дублируется текстом; управление доступно с клавиатуры; схемы увеличиваются. Мобильное чтение и простые действия поддерживаются; удобство полноценной стойки на телефоне проверяется отдельно.

Чертёж, 3D, траектория, проверка и прибор получают данные из одной версии детали. Разные значения погрешности прибора в учебных моделях обозначаются явно; нельзя незаметно переносить правило между ними. Проверка учитывает физические действия и актуальность замера, а не только введённое число.

Старые работы, зачёты, черновики и альтернативные истории не теряются. Ключи OpenRouter и вспомогательные средства разработки остаются вне приложения и поставки.

## 7. Ближайший выпуск: конкретный объём

Следующая реализация — очередь 1, без нового большого редизайна и массового пополнения статей:

1. Найти торец и ось на детали, затем на другом ракурсе.
2. Связать уменьшение X с уменьшением диаметра; различить X и радиус.
3. Переместить инструмент по Z без резания, назвать направление относительно торца и патрона.
4. До запуска предсказать траекторию на новой установке.
5. В подготовленной сцене оставить чистовой припуск и выполнить проход.
6. Остановить процесс по условиям сцены, выбрать нужную поверхность и получить свежий замер.
7. Объяснить остаток припуска или пересъём; выбрать допустимое дальнейшее действие.
8. Выполнить новое условие самостоятельно; сохранить результат и открытие помощи.

Экран всегда показывает систему координат, единицы и статус подготовки. Проверяется минимум одна ошибка знака, один устаревший замер и один необратимый пересъём. Вся цепочка проходит в браузере, через перезагрузку и облачное сохранение. Новые утверждения проходят РФ-0.

## 8. Как доказать качество и превосходство

Начальные пороги — наши продуктовые цели, не требования ГОСТа и не результаты проведённого исследования:

- Не менее 80% наблюдаемых новичков находят старт и выполняют первое осмысленное действие за две минуты без помощи наблюдателя. Чтение вводного объяснения не считается помощью.
- Не менее 80% выполняют полный цикл новой простой детали после курса без процедурной подсказки; ошибки и самостоятельные исправления учитываются отдельно.
- Не менее 75% выполняют сопоставимое новое условие через 3–7 дней. Срок, потери участников и помощь фиксируются.
- Критические ошибки безопасности показываются отдельно от общего балла; верные расчёты их не компенсируют. Классификацию проверяет предметный специалист.
- Все контрольные варианты имеют воспроизводимый эталон; регрессионные тесты проверяют варианты неверной логики, сохранение, права доступа и независимость историй.
- После каждого найденного затруднения проверяем, стало ли лучше после исправления; косметическая смена экрана не считается доказательством.

Для формирующего пилота достаточно начать с 6–10 новичков и преподавателя, заранее определить отсутствие опыта и правила помощи. Результаты такой небольшой группы служат исправлению продукта, не доказательству превосходства на рынке.

Для прямого сравнения нужны законный доступ к конкурентным продуктам, подходящие начальные программы и единые задания переноса. Нельзя сравнивать наш вводный курс с экзаменационным курсом Autodesk для опытных пользователей. Назначение групп случайное с учётом исходных знаний; одинаковые время, оборудование и разрешённая помощь; итоговая работа оценивается по единой рубрике без названия платформы. Выборку рассчитывать под выбранный основной показатель; фиксировать неопределённость и выбывших. При недоступности продукта ограничиться сравнением документированных функций.

## 9. Что ещё нужно проверить у конкурентов

Законно полученную демоверсию оценивать по одному протоколу: вход без знаний → доступность условия → первое неверное действие → объяснение причины → исправление → новое условие → восстановление после закрытия → отчёт преподавателю. Записывать версию, устройство, шаги, результат и длительность. Отдельно проверить клавиатуру, читаемость мелких размеров, работу на слабом ПК и отсутствие сети.

Сейчас не установлены количество активных клиентов, рыночные доли, завершение курсов, качество поддержки и эффективность обучения. Эти сведения не выдумывать. Не копировать чужие тексты, чертежи или датасеты: создавать собственные задания, заимствуя общие методические принципы.
