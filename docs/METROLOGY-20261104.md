## Что делает ученик

| Условие | Проверяемое действие |
| --- | --- |
| Поверхность и два сечения | Отличить шейку A от базы B; выбрать наружный прибор; проверить установку; записать два отсчёта и пределы |
| Глухое отверстие | Сопоставить вид и разрез; выбрать внутреннюю поверхность и подходящие губки |
| Разные результаты по длине | Отклонить деталь, если одно сечение негодно, несмотря на благополучное второе |
| Пограничное показание | Признать недостаточность результата штангенциркуля, затем заново измерить оба сечения микрометром |
| Деталь после доработки | Сначала оценить исходное состояние, получить новую учебную редакцию и заменить устаревшие замеры свежими |
| Самостоятельная втулка | Проконтролировать наружную и внутреннюю поверхности отдельно, заполнить четыре измерения и принять общее решение |

Первые два условия содержат объяснение и пример на других числах. Следующие требуют применения и диагностики. Последняя втулка имеет новый набор требований и пустой протокол. Запрос конкретного разбора записывается в журнал навсегда; результат с разбором не считается самостоятельным. Общая теория доступна без штрафа. Старые discovery/drawing занятия не переписаны автоматически этим пакетом.

## Модель и пределы

Размеры, разрешение и границы ошибки хранятся в целых микрометрах. Дисплей округляется до дискретности прибора. Для каждого свежего отсчёта `r` и заданной границы ошибки `e` рассчитывается `[r-e,r+e]`: внутри допуска включительно — «подтвердить»; целиком вне — «отклонить»; иначе — «уточнить». Касание допуска снаружи требует уточнения. Общее решение: любое негодное сечение отклоняет; иначе любое неопределённое требует уточнения. Интервалы разных поверхностей не смешиваются.

Это учебное правило, не заявление о реализации нормативной методики ГОСТ 8.051. Паспортные параметры четырёх виртуальных приборов заданы моделью, не заимствованы из таблиц ГОСТ. Микрометр проверяется по учебному эталону 25 мм, нутромер — 20 мм; штангенциркуль — без контролируемой детали. Температура, усилие, шероховатость, форма и доступ реальных губок не рассчитываются.

«После доработки» означает переход на заранее заданную редакцию виртуальной детали, а не новую операцию реального движка. Схемы показывают учебную геометрию и открытые торцы отверстий; это не аттестованные производственные чертежи.
