# Исходные заготовки — 28.10.2026

В обоих режимах мастерской доступны цилиндр и ступенчатая заготовка. Выбор сделан карточками с миниатюрами в форме «Новая заготовка». Для ступени задаются основной диаметр, общая длина/вылет, диаметр и длина меньшей передней ступени. В стойке отдельно задаётся длина в зажиме.

Передняя ступень расположена у свободного торца Z0, занимает интервал [−stepLength,0]. Большая часть находится со стороны патрона. Общая длина включает обе части. Ограничения: 5 ≤ stepDiameter < diameter ≤ 80 мм; 1 ≤ stepLength ≤ length−1 мм; длина 10–150 мм. Снимки цилиндра сохраняют прежний набор полей; ступенчатые добавляют shape=stepped, stepDiameter, stepLength.

Начальный профиль используется при съёме материала, расчёте снятого объёма, проверке столкновений и измерении. Ручное касание торца проверяет фактический диаметр передней поверхности. Пунктирная линия показывает исходную форму; 3D использует тот же профиль. Учебная программа и параметры первого прохода адаптированы к передней ступени.

Сброс возвращает исходную ступенчатую форму, сохраняя прежнюю работу. Импорт, экспорт и аккаунт сохраняют форму; старые цилиндрические работы совместимы. Новые эксперименты не дают зачёт курса. Формальная спецификация обновлена до 1.3.0.

Проверки: 28 основных групп, включая проверку начальных форм и 31 проверку стойки; 4 серверные группы; сборка с 49 скриптами. Проверены точный объём съёма, сохранность большой ступени, столкновение при переходе через уступ, отказ замера на границе, недопустимые параметры, касание торца, оба режима, восстановление, импорт, перенос в аккаунт и старые цилиндры. Серверный API проверен на сохранении обработанной ступенчатой детали и её исходной формы.

GLM 5.3 Flash через OpenRouter проверил контракт расширения. Его предложения сверены с фактически поддерживаемыми операциями: подрезка торца не добавлялась. Общая модель начальной формы реализована без внешних зависимостей; ключ разработки вне проекта.
