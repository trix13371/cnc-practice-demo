# Исправления интерфейса — 0.20.1

26.10.2026, по замечаниям пользователя к самостоятельной проверке этапа E.

- Панель выбора сложности экзамена получила тёмный фон, согласованные цвет текста, границу и скругление. Причина белого фона: основная таблица стилей задавала `background:white` всей панели, а тёмная тема переопределяла только вложенный `select`.
- Прямой вход: **«Ещё → Журнал проверки»**. Переход через результаты также сохранён. Активный пункт меню соответствует открытому журналу.
- Кнопки **«Скачать наблюдения · JSON»** и **«Скачать отчёт проверки · TXT»** доступны в верхней видимой панели «Журнал и сохранение». Там объясняется автоматическое сохранение после «Записать наблюдение» и порядок начала записей.
- Вкладка «Мой прогон» переименована в «Журнал наблюдений». Восстановление чужого/прежнего файла остаётся отдельным раскрывающимся блоком внизу.
- Учебные данные и структура сохранений не менялись. Форму наблюдения по-прежнему открывают после создания прогона, исходного снимка и начала наблюдения.

Проверка: два набора тестов пилота проходят, обе автономные сборки и проверка 39 подключаемых модулей проходят. В отдельном браузерном профиле открыт средний экзамен: фон панели `rgb(27,39,49)`, основной текст `rgb(232,238,242)`, описание `rgb(166,180,191)`. Проверены новый пункт меню и видимые кнопки сохранения в основном профиле; журнал оставлен открытым. Экзамен для проверки не запускался.
