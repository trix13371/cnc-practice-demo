# Локальный запуск в Docker

Проверено 03.11.2026. Адрес: **http://127.0.0.1:4180/**. Панель администратора: **http://127.0.0.1:4180/admin**.

Запускать команды из каталога с `compose.local.yaml`:

```powershell
docker compose -f compose.local.yaml up -d --build --wait
docker compose -f compose.local.yaml ps
```

При первом развёртывании новой пустой базы перед `up` требуется:

```powershell
docker compose -f compose.local.yaml build app
docker compose -f compose.local.yaml run --rm app node server/cli.cjs init
```

**На текущем стенде инициализация уже выполнена.** Команда `init` отказывается перезаписывать существующие аккаунты. Локальные аккаунты независимы от Beget: `admin` и `beta01`–`beta06`. Их пароли выданы в закрытый файл организатора `../../outputs/cnc-local-accounts.private.json`. Пароли не включать в Git и не отправлять всем участникам целиком. Первоначальная копия паролей из контейнера удалена после проверки экспорта.

При новом первом запуске файл выдачи `/data/initial-access.private.json` необходимо скопировать из контейнера в собственный закрытый файл организатора. Существующий экспорт не перезаписывать. После проверки копии файл выдачи можно убрать из контейнера: приложению он не нужен.

Порт опубликован только на `127.0.0.1`. Открывать нужно именно этот адрес: проверка Host/Origin не считает `localhost` тем же origin. Это локальный HTTP-стенд с `NODE_ENV=development`; production-конфигурация HTTPS, Caddy и доверенного прокси не изменена. На другом устройстве этот адрес указывает на само устройство, а не на компьютер со стендом.

Сервисы: `app` и `backup`. Образ: `cnc-practice-local:0.21`; отдельные volumes: `cnc-local_local_data` и `cnc-local_local_backups`. База и до 14 проверенных ежедневных копий сохраняются при перезапуске. Резервные копии на том же компьютере не заменяют внешнее хранение.

```powershell
# Остановить, сохранив аккаунты, работы и копии:
docker compose -f compose.local.yaml stop
# Посмотреть журнал:
docker compose -f compose.local.yaml logs --tail 60 app backup
```

Не использовать `down -v`: этот параметр удаляет volumes с данными. Для обновления исходников выполнить `up -d --build --wait`; рабочая папка не смонтирована в контейнер, поэтому правки требуют пересборки.

Известные ограничения версии и результаты проверки: [AUDIT-20261103.md](AUDIT-20261103.md).
