# Практика прямо на схемах — 26 октября 2026

В шаг «Попробовать» уроков machine, control и axes встроены три интерактивных упражнения, по три действия в каждом. Первое — найти заготовку, патрон и резец; второе — выбрать обработанную поверхность, хвостовик и среднее сечение; третье — указать продольное движение к патрону и поперечные направления к оси/от оси. Выбор выполняется на рисунке, затем подтверждается кнопкой.

Области — настоящие HTML-кнопки поверх SVG. Они доступны через Tab/Enter, имеют описательные aria-label и области нажатия от 44 px. Ошибка подсвечивает выбранную область и объясняет её смысл; следующее действие открывается только после правильного ответа. Подсказка вызывается отдельно. Изображение направлений не задаёт длину движения и не является готовой программой. В сцене контроля вращение явно остановлено.

Новая чистая модель discovery-practice-model.js восстанавливает состояние по журналу answer/next/hint. Сохраняются текущий выбор, пройденные действия, ошибки и подсказки. Журнал ограничен 256 событиями на упражнение; неверные переходы, чужие области, повреждённые и слишком длинные записи отвергаются. UI не доверяет полям complete/step из сохранённого JSON.

Данные хранятся в необязательном поле practice существующего cnc-course-path-v1. Старые форматы, зачёты и исследованные темы сохранены. Выполнение практики открывает самостоятельную проверку урока, но не выдаёт ответ урока и не увеличивает само по себе итог курса 0–22. Промежуточный результат передаётся на сервер и входит в общий JSON-перенос. При слиянии текущий локальный черновик сохраняется; другая ветвь остаётся в истории.

Проверка повторного импорта обнаружила добавление пустого состояния полного цикла в архив при повторном переносе нового аккаунта. mergeBooks теперь не архивирует состояния без действий; реальные попытки и их история сохраняются. Стабильность повторного импорта покрыта проверкой нового сценария.

Проверки: чистая модель, реальные обработчики урока, совместимость старого прогресса, JSON-перенос и повторное слияние; API сохранения выбранной области и отклонение поддельного перехода без изменения ревизии; весь набор учебных и серверных тестов. В отдельной локальной базе пройдены все девять действий, проверены неправильный выбор, подсказка, перезагрузка посреди упражнения, клавиатура, ширины 390 и 320 px.
